# Direktori Audio Latar (Backsound)
Letakkan file audio MP3 pernikahan di sini dengan nama `backsound.mp3`.
Jalur: `/music/backsound.mp3`

Jika file MP3 belum ditambahkan, aplikasi secara otomatis mengaktifkan synthesizer musik tradisional Gamelan Degung Sunda via Web Audio API, sehingga suara musik tetap terdengar lembut dan tidak pernah hening saat tamu membuka undangan.
